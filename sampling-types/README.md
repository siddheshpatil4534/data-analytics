# Sampling Types

This section covers different ways of selecting a smaller group of data from a larger dataset.

Here, I am learning and implementing three common sampling techniques using Python:

* **Simple Random Sampling** — selecting observations randomly from the complete dataset.
* **Stratified Sampling** — dividing the data into groups and selecting samples from each group.
* **Systematic Sampling** — selecting observations at a fixed interval from the dataset.

The implementations use a student performance dataset to understand how each sampling method works and how the resulting samples differ.
