# 🧹 Data Preprocessing

This project demonstrates fundamental data preprocessing techniques using the Titanic dataset. The notebook focuses on preparing raw data for machine learning by cleaning, transforming, and analyzing the dataset.

## 📌 Techniques Covered
- Handling missing values
- Feature scaling using StandardScaler
- Encoding categorical data
- Outlier detection using the IQR method

## 🛠️ Tools Used
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook
