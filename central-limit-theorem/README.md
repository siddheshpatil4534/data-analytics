# Central Limit Theorem

This section explores the Central Limit Theorem using the `math score` column from the student performance dataset.

The notebook compares the original distribution of scores with the distribution of sample means obtained from repeated samples.

### Topics Covered

* Original data distribution
* Repeated sampling
* Sample means
* Central Limit Theorem
* Before and after histograms

### Files

* `central_limit_theorem.ipynb`
* Uses `students_performance.csv` from the `sampling-types` folder
