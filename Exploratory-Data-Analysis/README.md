# Exploratory Data Analysis

## Objective

Perform Exploratory Data Analysis (EDA) on the Iris dataset using Python.

## Dataset

- Iris Dataset

## Topics Covered

- Data Loading
- Dataset Overview
- Descriptive Statistics
- Mean, Median and Mode
- Histogram
- Correlation Matrix

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
